# Active Bounties

There are no active bounties.

## About the MyNode Bounty System

The MyNode bounty system rewards community members for contributing features, improvements, and documentation to the project. Bounties help incentivize work on specific features or improvements that are needed by the community.

## How Bounties Work

1. **Bounty Announcement**: When a bounty is available, it will be listed in this document with a description of the work required and the reward amount.

2. **Claiming a Bounty**: To claim a bounty:
   - Review the bounty requirements carefully
   - Comment on the associated GitHub issue or contact the maintainers to express your interest
   - Wait for approval before starting significant work to ensure no one else is already working on it

3. **Completing Work**: 
   - Fork the repository and create a branch for your work
   - Implement the required changes following the project's coding standards
   - Test your changes thoroughly
   - Submit a pull request referencing the bounty

4. **Review Process**: 
   - Maintainers will review your pull request
   - Address any feedback or requested changes
   - Once approved and merged, you will be eligible for the bounty reward

5. **Receiving Rewards**: 
   - After your pull request is merged, contact the project maintainers to arrange payment
   - Payment details and methods will be discussed directly with maintainers
   - Rewards are typically paid in Bitcoin or Lightning Network payments

## Frequently Asked Questions

**Q: Will I receive the reward if my pull request is merged?**  
A: Yes, once your pull request is merged and meets all the bounty requirements, you are eligible to receive the bounty reward. Contact the maintainers to arrange payment.

**Q: Can I work on a bounty without claiming it first?**  
A: It's recommended to claim a bounty first to avoid duplicate work and ensure the bounty is still available.

**Q: What if there are no active bounties?**  
A: You can still contribute to the project! Check the GitHub issues for areas where help is needed, or propose new features and improvements.

**Q: How long does it take to receive the reward?**  
A: Payment timing varies depending on the maintainers' availability. Contact them directly after your PR is merged to arrange payment.
